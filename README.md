# Photo Roulette（照片轮盘）

一个完全离线的 Android 相册整理工具：每天随机挑选少量照片，用手势快速决定保留、移入系统回收站，让整理相册变成每天的几分钟小事。

## 功能

**每日整理**
- 从媒体库按当日设置抽取一批照片（默认 10 张），队列在当天持久保存，杀进程也能接着滑。
- 抽取策略三选一：随机 / 最旧优先 / 体积最大优先；可限定日期范围（全部 / 最近一年 / 一年以前 / 自定义起始日）与相册白名单。
- 整理页左滑删除、右滑保留，支持撤销误操作。
- 全屏预览：双指缩放、双击放大、下滑关闭，宫格 ↔ 预览共享元素转场；视频可直接播放。

**回收站**
- 已删除项在 App 回收站中宫格浏览，支持多选恢复或永久删除（均通过系统回收站两段式确认，App 不直接删文件）。

**统计与回忆**
- 周统计卡片、趋势图、月历热力图；累计整理/删除/保留计数独立持久化，不受清理影响。
- 「回忆时光机」按月回看处理历史。

**每日提醒**
- 精确闹钟（AlarmManager 三级降级）到点发通知，点击通知直达整理页；开机、应用更新、时区变化后自动恢复。

**其他**
- 深色 / 浅色 / 跟随系统主题。
- 隐私：仅使用 MediaStore 本地扫描，照片不会上传或复制；联网能力为零。

## 打开和构建

1. 使用 Android Studio 打开本目录。
2. 安装 Android SDK Platform 36，并使用 JDK 17。
3. 让 Gradle 同步依赖后运行 `app`。
4. 首次启动时授予「照片和视频」与「通知」权限，然后点「重新扫描相册」选择要包含的相册。
5. 想要准点的每日提醒，请在系统设置中为本 App 授权「闹钟和提醒」（未授权时自动降级为非精确提醒）。

## 兼容性

仅支持 Android 16（API 36，`minSdk = targetSdk = compileSdk = 36`）。

## 架构一览

轻量 MVVM、单向依赖、无 DI 框架：

```
MediaStore ── MediaScanner ─┐
DataStore ── SettingsRepo ──┼→ PhotoRepository → PhotoViewModel → Compose UI
Room(photos 表) ────────────┘
```

- 数据一致性靠启动/回前台时与系统媒体库「对账」：外部删除、系统回收站恢复、MIUI 清理等都能对上，不会误判。
- 删除走 `MediaStore.createTrashRequest` 系统回收站流程，App 侧先落地 `PENDING` 状态、系统确认后才提交。

整体架构评审与问题清单见 [architecture-review.md](architecture-review.md)。
