# Photo Roulette（照片轮盘）

一个完全离线的 Android 相册整理工具：每天随机挑选少量照片，用手势决定保留、移入系统回收站。

## 功能

- 使用 MediaStore 扫描设备相册；照片本身不会上传或复制。
- 每天默认随机挑选 10 张，队列在当天持久保存。
- 左滑删除（移入系统相册回收站并显示系统确认）；右滑保留。
- Room 保存每张照片的处理状态；已保留、删除的项目不再参与随机抽取。
- 设置每日数量、是否纳入视频/截图；支持浅色和深色主题。
- 已提供 WorkManager 每日提醒调度器；保存设置后可接入提醒时间。

## 打开和构建

1. 使用 Android Studio 打开本目录。
2. 安装 Android SDK Platform 35，并使用 JDK 17。
3. 让 Gradle 同步依赖后运行 `app`。
4. 首次启动时授予“照片和视频”权限，然后点“扫描相册”。

仅支持 Android 16（API 36）。删除的照片通过系统回收站请求移入系统相册回收站，不会直接永久删除；可在 App 回收站中恢复或永久删除。
